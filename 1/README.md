# Задание 1: сравнение ХКУ и кеплерова движения

Откройте `compare.sce` в VS Code и нажмите `Ctrl+Shift+B`. Для запуска нужны Scilab 2026.1.0 и графическая среда. Скрипт рассчитывает 90 вариантов и сохраняет таблицу `results/comparison.csv` и PDF-графики `results/case_01.pdf` — `case_90.pdf`. Порядок случаев описан в отчёте.

`report.pdf` содержит анализ, четыре примера и таблицу для всех случаев. Исходники отчёта — `report.tex` и `table.tex`. Вопросы для защиты приведены в `questions.md`.

Для воспроизводимости отчёта оставьте прилагаемый `table.tex` вместе с `report.tex`; после изменения параметров модели таблицу и численные выводы отчёта потребуется обновить. Сборка из папки `1`: `pdflatex -interaction=nonstopmode -halt-on-error report.tex` (дважды).
