# Проект SamylLab

В VS Code настроены задачи для Python-задания 3 и Scilab. Материалы и код третьего задания находятся в папке `3`.

## Запуск

1. Откройте эту папку в VS Code.
2. Откройте файл `.sce` или `.sci`.
3. Для запуска модели задания 3 нажмите `Ctrl+Shift+B` — Python сохранит расчёт в `3/results/`.

Для Scilab откройте файл `.sce` или `.sci`, затем в палитре команд (`Ctrl+Shift+P`) выберите **Tasks: Run Task** и нужную задачу Scilab. Задача с графиками называется **Scilab: Run current file with graphics**.

`3/main.sce` содержит небольшой пример Scilab. Создавайте скрипты с расширением `.sce`, а функции сохраняйте в `.sci`.

## Настройка установки Scilab

Путь к установленному Scilab для языковых функций расширения VS Code задан в `.vscode/settings.json` (`Scilab.SCI`). Если Scilab установлен в другом месте, измените это значение на путь к корневой папке установки. Для запуска задач команда `scilab` должна быть доступна в `PATH`.
