# Задание 2 — фазовые портреты ХКУ

В основе — случаи №1, №3 и №65 из задания 1. Для каждого добавляется поперечное движение, рассчитанное по сетке наклонений и истинных аномалий. Скрипт сравнивает ХКУ с независимым двухтельным движением и сохраняет 36 графиков PDF и таблицу `results/grid_summary.csv`.

Откройте `hcw_phase_portraits.sce` в VS Code и нажмите `Ctrl+Shift+B`. Номер после `case_` в имени PDF соответствует базовому случаю первого задания, `i01`–`i03` — относительным наклонениям 0,01; 0,1 и 0,5 градуса, `nu` — истинной аномалии в градусах. Обратите внимание: наклонение добавляет к базовым случаям поперечное положение и скорость.

`report.pdf` содержит анализ и четыре примера; `questions.md` — вопросы для защиты. Отчёт пересобирается из папки `2` двукратным запуском `pdflatex -interaction=nonstopmode -halt-on-error report.tex`.
